# Create an AI Agent Without Writing Any Code

An AI agent is a software system that uses artificial intelligence to understand goals, make decisions, and take actions autonomously on a user’s behalf.

Would you like to build an AI Agent, but do not have the time to learn all the latest frameworks and technologies?

Good news! Tools exist to quickly create an agent that allows your users and customers to interact with your files, sites, and other resources, via a natural language, such as English.

In this session, I will show you multiple ways to create, test, and deploy an AI Agent without writing a single line of code!
